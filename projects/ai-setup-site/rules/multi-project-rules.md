# Multi-Project Workspace Rules

Treat each repository or project folder as an independent workspace.

- Run commands from the intended project root.
- Keep dependencies, configuration, build output, and environment files inside that project.
- Do not copy source files, credentials, generated output, or configuration between unrelated projects.
- Read the target project's README, local instructions, and package configuration before changing code.
- Use project-specific AI guidance when it exists; it supplements rather than replaces repository-level standards.
