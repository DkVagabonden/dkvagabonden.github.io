This static guide explains the moving parts and safety boundaries. It does not install, configure, connect to, or run an MCP server.

01

Static website

Know what this site does not do

ServiceNow MCP Desk publishes HTML, CSS, browser JavaScript, and JSON catalog metadata. It has no backend, receives no credentials, makes no authenticated ServiceNow requests, and cannot execute an MCP tool.

02

Core concepts

Separate the MCP roles

A host contains the AI experience, a client maintains the connection, a server exposes capabilities, and a tool performs a bounded operation. This catalog documents tool ideas; it is none of those runtime components.

Open the tool catalog
HostContains the AI experience
ClientConnects to an MCP server
ServerExposes approved capabilities
ToolDescribes one bounded operation
03

Outside this repository

Keep runtime responsibilities elsewhere

An actual implementation must independently choose a supported MCP SDK and transport, authenticate to ServiceNow, enforce table and field policy, protect secrets, log safely, and test failure cases. This public catalog supplies no implementation or configuration.

AuthenticationNever belongs in this site
AuthorizationEnforce on every operation
ObservabilityExclude secrets and sensitive data
TestingBegin in non-production
