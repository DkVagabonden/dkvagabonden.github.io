Controlled-write design

Treat write patterns with care

The catalog includes no published write patterns. Any future entry should document scope, table, field, environment, audit, and rollback requirements.

User-friendly design

Keep questions bounded and explainable

A user-facing pattern should describe how plain-language requests become approved read-only queries and how filters, limits, and assumptions remain visible.
